下载 Mac 应用 · Apple 芯片 安装说明

1.3.0 预览版 · macOS 13 或更新版本 · Google Chrome。

安装与连接

  1. 下载并解压 Mac 应用，将 Chrome Tab Router.app 放入 ~/Applications，然后打开。安装包使用临时签名，尚未经过 Apple 公证；macOS 如阻止首次打开，可按照 Apple 的说明在“系统设置 → 隐私与安全性”中确认打开。
  2. 点击菜单栏中的应用图标。在“默认浏览器”中选择“设为默认浏览器”，即可接收外部应用打开的 HTTP/HTTPS 链接；Chrome 网页内部的新标签页链接还需要安装配套扩展。
  3. 扩展当前仍为商店草稿。测试时从 Mac 菜单栏“Chrome 扩展”中打开自带的扩展目录，在 Chrome 的 chrome://extensions/ 开启开发者模式，选择“加载已解压的扩展程序”并选择该目录。也可使用 扩展 ZIP，解压后选择包含 manifest.json 的文件夹。
  4. 正式扩展的本机连接由 Mac 应用每次启动时自动登记，扩展会在安装、Chrome 启动和打开弹窗时检测连接。先安装扩展、再安装 App 时，首次打开 App 后返回扩展弹窗或欢迎页，点击“重新检测”。本地开发版首次使用或修复连接时，在扩展弹窗点击“修复连接”，允许打开应用并确认连接请求，然后重新检测确认“已连接”。首次路由链接时，允许 Mac 应用控制 Google Chrome。

Chrome Web Store 项目在上架后可直接安装；当前还未提交审核。安装前已经打开的网页需刷新一次，让扩展脚本加载。

在菜单栏调整行为

可以暂停标签页复用、选择切换后是否刷新、是否更新为收到的新链接、是否查找所有 Chrome 窗口，以及登录时自动启动。扩展和 Mac 应用读取同一份设置，修改后自动保存。

  • “网址匹配”：选择忽略页面锚点、常见跟踪参数或全部查询参数。路径始终参与匹配。
  • “例外网站”：添加、查看和删除域名。这些域名及其子域名每次新开标签页。
  • “Chrome 扩展”：查看自动连接配置和最近连接记录，选择“安装 Chrome 扩展…”或“修复自动连接”，以及打开扩展目录、安装说明和隐私政策。扩展弹窗显示本次检测是否已连接。
  • “默认浏览器”：设为默认浏览器，或恢复原来的默认浏览器。

网页点击接管支持指向新标签页的链接、Command 点击和鼠标中键点击。Chrome 内部页面、Chrome Web Store、地址栏、书签、右键菜单、表单和脚本调用 window.open() 不在接管范围内。
